# bp-practice · 汉语 b / p 送气音与不送气音 在线练习

面向**母语为英语的初级汉语学习者**的 10 分钟语音微课配套在线练习。
核心目标：听辨并区分 **b [p]（不送气）** 与 **p [pʰ]（送气）**——两个音发音部位完全相同，唯一差别是**送气**。

## 打开就能用

https://au77u.github.io/bp-practice/

无需安装、无需下载素材，网页是**单个自包含 HTML 文件**（全部代码与音频合成逻辑都内嵌）。

## 两个练习

| 模块 | 题量 | 形式 |
| --- | --- | --- |
| 听辨闯关 | 8 题 | 播放 A、B 两个音节，判断哪个是送气音 |
| 判断题 | 6 题 | 听一个音节，判断它是不是送气音 |

- **答错不跳题、不直接给答案**：自动重播 A→B 对比音，学生可在**原题上重新选择**。
- 答对计入「答对」，订正正确计入「订正」，两者分开统计；全部做完后可「只练错题」。
- 教师可上传真人录音覆盖默认音源（文件名用「拼音+声调数字」，如 `bao1.mp3`、`bao3.mp3`）。

## 声音

默认使用**设备自带的中文真人语音**（`speechSynthesis`），最自然；
若设备没有中文语音（如部分安卓微信），自动回落到**内置合成音**，不会没声音。

合成模型：闭塞段 50 ms → 爆破 6 ms → 送气噪声段（b ≈ 8 ms / p ≈ 95 ms）→
元音共振峰 F1/F2/F3 + 声调基频曲线。**b 与 p 的唯一差别就是送气段长度**，与语音学定义一致。

## 教学要点（英语母语者）

- 英语 /p/ 本身有两套：**pie** 词首送气、**spy** s 后不送气——正好对应 p 和 b，可做正迁移。
- 用纸巾实验可视化送气：念 p 纸巾飘，念 b 纸巾不动。
